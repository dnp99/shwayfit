# ShwayFit repository instructions

ShwayFit is a phone-first client-management application for independent fitness trainers.

Read [AGENT.md](AGENT.md) before making any change. It contains the repository's engineering, privacy, API, and deployment rules.

Before creating or changing UI, read [docs/design-system.md](docs/design-system.md). Use semantic Tailwind tokens and shadcn/ui primitives, preserve light and dark themes, and maintain phone-first responsive behaviour.

Do not introduce a new colour palette or component-styling convention without updating the design-system documentation.
