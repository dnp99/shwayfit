# Frontend design-system history

The active ShwayFit UI specification is [design-system.md](design-system.md). This retained document records the original adoption decision; it is not a second source of truth.

Tailwind CSS, official shadcn/ui primitives, semantic CSS tokens, Lucide icons, and System/Light/Dark mode are active in the authenticated application shell. The landing page remains intentionally lightweight; [design-system.md](design-system.md) is the current specification.
